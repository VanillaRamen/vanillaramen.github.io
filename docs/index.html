Stack

Right now, I'm using a Lenovo Legion laptop running Arch Linux as my daily driver operating system.

My display server is Wayland, and my Wayland compositor is Niri.

My preferred terminal emulator is Kitty, my preferred interactive shell language is Bash, and my preferred text editor is Vim.

I haven't tried Neovim yet, but I probably won't use it.

My favorite programming language is C! I love its simplicity and how flexible the syntax is. The freedom I have when writing C is a large part of why I enjoy it so much, especially compared to something like Rust.

C++ is fine as well, but I don't like to use it much beyond its more basic features.
