Computing Stack

I currently do (basically) everything on a laptop running Arch Linux.

I use Wayland, rather than X window system. For a Wayland compositor, I use Niri paired with Noctalia Shell.

My favorite programming language is C. For a compiler, I use gcc. I also like to write scripts in bash. I'll use C++ if I have to, but I never find myself reaching for it. The same goes with Python.

For a terminal emulator, I like to use kitty.
